# 온기 (ONGI)

> **감성적 영구 분산 보존 기반 1인칭 AI 가족 추모 플랫폼**  
> *A Perpetual Decentralized 1st-Person AI Memorial & Family Heritage Archive*

---

## 프로젝트 개요

**온기 (ONGI)**는 생전(사전 기록)과 사후(유족 아카이빙)의 가족 데이터를 정형화된 개인화 Key-Value(Layer 1/2)로 추출하여 전 세계 분산 보존 네트워크(Arweave)에 영구 보존하고, 엄격한 헌법적 가드레일 하에 **고인의 1인칭 시점**으로 유족과 따뜻하게 소통하는 모바일 디지털 유산 플랫폼입니다.

* **타겟 플랫폼:** Android 우선 출시 (구글 플레이 14일 비공개 테스트 검증) $\rightarrow$ iOS 확장
* **클라이언트 스택:** Flutter 3.x
* **스튜디오 허브:** [https://graviton94.github.io/](https://graviton94.github.io/)

## 전사 절대 금기 4대 헌장 (Non-Negotiable Rules)

1. **시스템 이모지(Emoji) 사용 전면 금지 (No Emojis Policy):**
   * UI 아이콘 및 데코레이션에 시스템 이모지 사용을 엄격히 금지합니다.
   * 모든 시각적 기호는 정밀한 미니멀 벡터 라인(SVG)으로만 구성합니다.
2. **차가운 행정·법률 용어 전면 금지 (감성적 완곡어법 의무화):**
   * `고인(故人)`, `사망`, `죽음`, `생존 확인`, `사후 전환` 등 병원/법원 서류 같은 직설적 단어를 100% 배제합니다.
   * `소중한 분 / 그리운 분`, `먼 여행을 떠나셨을 때 / 별이 되신 날`, `기억 상자 열기`, `따뜻한 일상 안부 여쭙기` 등 유족의 슬픔을 위로하는 고품격 언어 체계만 사용합니다.
   * 예외: 이용약관·개인정보처리방침·결제 고지 등 법적 문서는 정확한 법률 용어를 쓰고, 앱 화면에 완곡어법 요약을 함께 둡니다. ([문서 01](documents/01_service_master_blueprint.md) 참고)
3. **AI 슬롭(AI-Slop) 시각 효과 배제:**
   * 조잡한 바운스 애니메이션, 촌스러운 원색 그라데이션, 과장된 쉐도우를 배제하고 자연스러운 페이드와 은은한 호흡(Breathing) 모션만 적용합니다.
4. **인위적인 페르소나 왜곡 금지:**
   * 고인의 성향이나 말투를 슬라이더로 조작하는 게임적 UI를 금지하며, 원본 데이터와 팩트 시트에 기반한 진실성만 유지합니다.

## 디자인 톤 체계

* **기본 톤 (Primary & Default): 한지 & 앤티크 우드 & 세이지 그린 (Hanji & Timber)**
  * **바탕 (Parchment Base):** 부드러운 전통 한지 크림 (`#F9F6F0` / `#F3EFE6`)
  * **뼈대 (Antique Timber):** 묵직한 고목 흑갈색 (`#2C221E` / `#3D312A`)
  * **생명과 안식 (Sage Green):** 자연의 평온함을 주는 세이지 솔잎 초록 (`#5B7065` / `#748A7E`)
  * **빛과 온기 (Soft Amber):** 등불의 온기를 담은 웜 베이지 앰버 (`#C99A5B`)
* **다크 톤 (Secondary Theme): 심야의 밤하늘 (Obsidian Twilight)**
  * 야간 몰입을 위한 심야 흑색 (`#080A0E`), 미드나잇 슬레이트 (`#121620`) & 샴페인 골드 (`#D8B26E`)
* **타이포그래피:** 고인의 말씀은 `Noto Serif KR` (본명조), 시스템 정보는 `Pretendard` / `Plus Jakarta Sans`.

## 데이터 보안 및 무결성 원칙

* **보관 데이터 암호화:** 기억 코어와 대화 기록은 단말기에서 생성된 마스터 키로 AES-256-GCM 암호화한 뒤 보관합니다. 스튜디오 서버와 보존 네트워크에는 암호문만 남으므로, 보관된 기록을 스튜디오가 열람할 수 없습니다.
* **대화 생성 시 전송 범위 고지:** 1인칭 대화를 만들 때는 그 순간 필요한 기억 조각과 대화 내용이 TLS로 AI 제공사에 전송됩니다. 게이트웨이는 이를 저장하지 않고 중계만 하며, 제공사의 API 데이터 정책(모델 학습 미사용 등)을 개인정보처리방침에 명시합니다. 따라서 "누구도 절대 열람할 수 없다"는 표현은 사용하지 않습니다.
* **영구 보존의 한계 고지:** 마스터 키를 잃으면 보존된 기록은 남아 있어도 열 수 없습니다. 복구 QR 보관의 중요성을 반복 안내하며, 특정 기간의 보존이나 암호 안전성을 "보증"하는 표현은 쓰지 않습니다.
* **지갑 없는 영구 봉인:** 유저는 가상자산 지갑을 몰라도 됩니다. 스튜디오가 Turbo(ar.io) 업로드 크레딧으로 비용을 대신 내고 Arweave에 봉인합니다. 봉인되는 것은 그리운 분의 말에서 추출한 암호화된 기억 코어뿐이며, 다른 가족·지인의 메시지 원문은 올리지 않습니다.
* **삭제 요청 = 키 영구 파기:** 블록체인 기록은 지울 수 없으므로, 삭제 요청 시 해당 기록의 암호 키를 모든 단말과 백업에서 영구 파기해 복원이 불가능하게 만듭니다(개인정보 보호법 시행령 제16조의 파기 인정 근거). 봉인 전에는 7일간 되돌릴 수 있는 숙고 기간을 둡니다.
