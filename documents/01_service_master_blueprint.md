## 1. 전사 언어 및 UX 헌장 (감성적 완곡어법 딕셔너리)

> [!IMPORTANT]
> 본 플랫폼의 모든 UI, 푸시 알림, 안내문에는 **'고인', '사망', '죽음', '생존' 등 직설적이고 차가운 법률·행정 용어 사용을 전면 금지**합니다. 가족의 슬픔을 보듬는 격조 높은 완곡어법만 허용합니다.
>
> **예외 (법적 명확성 우선):** 이용약관, 개인정보처리방침, 결제·환불 고지처럼 법적 효력을 갖는 문서는 의미가 모호해지지 않도록 정확한 법률 용어를 사용합니다. 대신 앱 화면에서는 완곡어법으로 쓴 요약을 함께 보여줍니다.

| 기존 직설적 표현 | 본 서비스 표준 감성 표현 | 사용 예시 |
| :--- | :--- | :--- |
| **사망 / 사후** | **먼 여행을 떠나셨을 때 / 별이 되신 날 / 안식에 드셨을 때** | "소중한 분께서 먼 여행을 떠나신 후..." |
| **고인 (故人)** | **그리운 분 / 소중한 분 / 기억 속 그분** | "소중한 분의 따뜻했던 말투를 복원합니다." |
| **영정 사진** | **가장 빛나던 순간의 모습 / 대표 기억 사진** | "가장 따뜻하게 웃으시던 대표 사진을 등록해주세요." |
| **유족 (遺族)** | **기억을 이어가는 가족 / 남겨진 가족** | "기억을 이어가는 가족들을 위한 공간입니다." |
| **생존 확인 알림** | **따뜻한 일상 안부 여쭙기** | "소중한 분들의 마음이 담긴 기억 상자가 준비되었습니다. 평안한 일상을 보내고 계신가요?" |
| **사후 모드 전환** | **추모의 방 개봉 / 영구 기억 상자 열기** | "가족들의 합의로 기억 상자를 엽니다." |
| **블록체인 / 지갑** | **국제 분산 보존 네트워크 / 영구 암호화 금고** | "전 세계 분산 보존 네트워크에 안전하게 암호화 보관됩니다." |

## 2. 핵심 아키텍처 대원칙

1. **Zero-Maintenance 보존 (보존 비용 1회 완납 모델):**
   * 영구 기억 코어(Layer 1/2)는 Arweave에 1회 완납 보존. 업로드는 Turbo(ar.io) 크레딧으로 스튜디오가 대납 (Irys는 Arweave 지원을 종료해 사용하지 않음).
   * **봉인 대상은 그리운 분의 말에서 추출한 기억 코어뿐**입니다. 카톡 원문에 섞인 다른 가족·지인의 메시지, 이름, 연락처는 봉인하지 않고 단말과 유저 개인 클라우드에만 둡니다.
   * 대용량 원본 파일은 유저 개인 클라우드(Google Drive / iCloud) 연동.
   * 미구독자 서버 동기화 데이터는 30일 후 자동 퇴거(Cold Eviction) 처리.
   * **주의:** "0원"은 보존 비용에만 해당합니다. AI 대화 생성 비용은 대화할 때마다 계속 발생하므로 구독 수익으로 충당해야 합니다.
2. **시공간 인지 (Time Anchor + Dynamic Learning):**
   * **Layer 1 (시공간 닻):** 먼 여행을 떠나신 시점에 지식과 가치관을 고정 (억지 최신 유행어 배제).
   * **Layer 2 (지속적 기억 축적):** 가족들이 대화창에서 전하는 최근 근황(취업, 결혼 등)을 RAG로 학습하여 다음 대화에서 *"지난번에 큰애가 승진했다고 했지? 정말 대견하더구나"*라며 지켜보고 있는 듯한 따뜻함 전달.
3. **봉인과 파기 (Seal & Shred):**
   * **숙고 기간:** "기억 상자 봉인"을 누르면 7일 뒤에 실제 업로드됩니다. 그 전에는 언제든 취소할 수 있습니다.
   * **삭제 요청 처리:** 봉인 후 삭제 요청이 오면 해당 기록의 암호 키를 단말, 복구 QR 재발급 경로, 서버 백업에서 모두 영구 파기합니다. 블록체인에는 복원할 수 없는 암호문만 남습니다. 개인정보 보호법 시행령 제16조는 기술적 특성상 영구 삭제가 곤란할 때 복원이 불가능하도록 처리한 것을 파기로 인정합니다.
   * **키 설계 원칙:** 기록마다 별도의 데이터 키를 쓰고(키 재사용 금지), 마스터 키로 감쌉니다. 그래야 기록 단위로 파기할 수 있습니다.
4. **헌법적 가드레일 (Constitutional Guardrail):**
   * 상속/재산 분쟁 편들기 유도 시: 어떠한 사실 확인도 거부하고 평화 원칙으로 강제 전환.
   * 극단적 우울감/자해 암시 시: **1인칭 페르소나를 즉시 내려놓습니다.** 위기의 순간에 그리운 분의 목소리로 말하는 것은 의존을 키우거나 판단을 흐릴 수 있기 때문입니다. 대신 서비스 자신의 목소리로 짧고 따뜻하게 안부를 묻고, 실제 도움 창구(자살예방 상담전화 109, 정신건강 위기상담 1577-0199)를 바로 연결할 수 있는 화면을 띄웁니다. 감지 결과는 대화 세션에 기록되어, 이후 대화에서도 페르소나가 위기를 가볍게 넘기지 않도록 합니다.

## 4. 결제 구조 (대화는 넉넉히, 부가 기능은 유료)

> 대화 도중 결제 벽을 세우지 않습니다. "그리운 분과 이야기하려면 결제하세요"로 읽히는 순간 서비스의 신뢰가 무너지기 때문입니다.

1. **무료:** 카톡 .txt 업로드 $\rightarrow$ 팩트 시트 $\rightarrow$ 인격 카드 확인 $\rightarrow$ 매일 넉넉한 횟수의 1인칭 대화. 한도에 닿으면 대화를 끊지 않고 "오늘 이야기는 여기까지 담아둘게요" 같은 마무리 인사로 하루를 닫습니다.
2. **영구 봉인 (단건 IAP):** Arweave 봉인 + 마스터 복구 QR + 봉인 기록 증명서(트랜잭션 ID 포함). 보존 기간이나 암호 안전성을 "보증"하는 표현은 쓰지 않습니다.
3. **가족 구독:** 대화 한도 해제, 하늘 추모관, 명절·기일 카드, (Phase 2) 음성. 크레딧 제도는 MVP 이후 필요할 때 다시 검토합니다.
4. **원가 관리:** 구독자 1인당 월 AI 비용을 출시 전 테스트 데이터로 추정해 [문서 06](06_mvp_scope_and_decisions.md)에 기록하고, 무료 일일 한도를 그 값에 맞춰 정합니다.
